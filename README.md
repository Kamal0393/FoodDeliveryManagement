# FoodDeliveryManagement



\# Food Delivery Management System



\## Project Overview

A Core Java console-based Food Delivery Management System developed collaboratively by a team of five members.



\## Technologies

\- Java

\- Object-Oriented Programming

\- Collections Framework

\- Git and GitHub



\## Project Modules

1\. User Management

2\. Restaurant \& Food Management

3\. Cart Management

4\. Order \& Bill Management

5\. Payment \& Delivery Management



\## Project Structure

Each module follows a layered architecture:

\- Model

\- Repository

\- Service

\- CLI



\## Team Development

Each member develops an assigned module in a separate Git feature branch. Completed modules are submitted through Pull Requests for review and integration into the main branch.



\## Execution

The application will be launched through the main entry point in `src/app/Main.java` after module integration.
